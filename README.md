# AI Study Assistant — Module 5 Mini Project

## About
AI Study Assistant is a simple student-focused web application created for Module 5 (AI Tools & Mini Project). It demonstrates how an AI-style tool can support learning, coding preparation, research planning, and productivity.

## Features
- Explain a topic in simple language
- Create short study notes
- Generate practice questions
- Create a learning roadmap
- Responsive HTML/CSS/JavaScript interface
- Demo mode works without an API key

## AI Tools Explored
- ChatGPT — coding assistance, explanations, debugging, research planning and productivity
- Google Gemini — alternative AI assistant for research and brainstorming
- Microsoft Copilot — coding and productivity assistance

## How AI Tools Help
### Coding
AI tools can explain errors, suggest approaches, generate starter code and help debug programs. Code should still be reviewed and tested by the developer.

### Research
AI can help create search keywords, summarize information, compare concepts and organize notes. Important facts should be verified with reliable sources.

### Productivity
AI can help create study plans, checklists, outlines, revision questions and project documentation.

## Run the Project
1. Download or clone this repository.
2. Open `index.html` in a browser.
3. Enter a topic and select a task.
4. Click **Generate**.

## Real AI Integration
The current project intentionally runs in demo mode so no secret API key is exposed in frontend code. For a production version, connect the UI to a secure backend that calls an AI API and stores the API key only on the server.
